## progObiekt
Repozytorium do zajęć z [programowania obiektowego](https://simple.wikipedia.org/wiki/Object-oriented_programming) w języku C++.

### :mag: Zawartość
- c01: projekt DateTime
- c02: projekt Point
- c03: projekt Vector/Matrix
- ulamki: projekt Rations
- c04: template Stack, stos LIFO
- c05: ćwiczenia z template, konkretyzacja
- FIFO: projekt FIFO
- FIFOtemplate: projekt FIFO przerobiony na template
- jcw1-9: wstęp do Javy
- Reader: projekt Reader, czytanie znaków
- School: projekt School, dane uczniów i pracowników
- StackList: projekt Stack w formie listy w Javie
- StackT: projekt Stack template w Javie
- test: projekt DLL (ang. Dynamic Link Library)
